# MacBros Detailing Website

Production-ready Next.js marketing site for MacBros Detailing.

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- Nodemailer for quote and callback delivery

## Local Development

```bash
corepack pnpm install
corepack pnpm dev
```

Open `http://localhost:3000`.

## Environment Variables

Copy `.env.example` to `.env.local` and set:

- `NEXT_PUBLIC_SITE_URL`
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_SECURE`
- `SMTP_USER`
- `SMTP_PASS`
- `SMTP_FROM`
- `CONTACT_TO_EMAIL`

Without the SMTP variables, the quote and callback forms will render but will return a server configuration error when submitted.

## Email Setup

Recommended production setup:

1. Create or enable the real mailbox `info@macbrosdetailing.com`.
2. If you want messages to land in a personal inbox too, add forwarding from `info@macbrosdetailing.com` to that inbox.
3. Use the mailbox provider's SMTP credentials for `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, and `SMTP_PASS`.
4. Set `SMTP_FROM` to `MacBros Detailing <info@macbrosdetailing.com>` only if the provider allows sending from that address.
5. Publish SPF, DKIM, and DMARC for the sending domain before launch.

Important:
Inbox forwarding by itself does not provide authenticated outbound email. The website still needs real SMTP credentials from the mailbox provider or a transactional email provider.

## Validation

```bash
corepack pnpm typecheck
corepack pnpm build
```

## Deployment Notes

- The forms submit to `/api/quote` and `/api/callback`.
- Quote requests support up to 5 image attachments, 5 MB each, 15 MB total.
- Security headers are configured in `next.config.mjs`.
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest`, structured data, and an Open Graph image are generated by the app.
- Set `NEXT_PUBLIC_SITE_URL` to your live domain before deployment.
